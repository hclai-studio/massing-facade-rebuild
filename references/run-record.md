# 运行记录

未记录的字段填写“无记录”；尚未确认的字段填写“待确认”，不要根据文件时间或印象补猜。

| 字段 | 填写内容 |
| --- | --- |
| 模型 | 模型全称与可用的版本标识 |
| 推理强度 | 实际设置；未知则写无记录 |
| 提示词 | 完整原文，或可追溯的文本文件路径；续跑追加各轮原文 |
| 3D 输入 | 文件名／路径、格式、版本、来源、源文件校验值 |
| 图片输入清单 | 逐张列出文件名／路径、用途（几何核对／目标图／局部裁图）、版本及确认状态 |
| 出图轮数 | 首轮出图加后续实际出图轮次；同轮多张候选图不重复计轮。直接使用已确认目标图且未出图时填 0；历史不详则填无记录 |
| 每轮追问内容 | 按下表逐轮保留完整追问原文，并对应 `render_prompt.txt` 中的轮次；首轮填初始提示词，没有追问写无，不根据结果补猜 |
| 开始时间 | YYYY-MM-DD HH:MM:SS，注明时区 |
| 结束时间 | YYYY-MM-DD HH:MM:SS，注明时区 |
| 执行时长 | 总历时；如扣除等待，分别列主动执行、等待和续跑时长及计算依据 |
| 渲染／QA 批次 | 批次总数及下表明细；区分仅渲染与完成检查的批次 |
| 几何反馈循环次数 | 次数及依据；一次循环指“收到几何反馈 → 修改 → 复核”，不按图片张数计数 |
| 额度状态 | 开始／结束时可核实的剩余额度、是否中断、恢复时间；无法获取则写无记录 |
| 输出文件 | 文件名／路径、用途、状态（过程／待核验／最终）、相关核验报告 |
| 最终用户或 QA 结论 | 评价人、时间、结论原文、证据位置；没有验收时写待确认 |
