# 立面几何术语表 / Facade geometry vocabulary

用于洞口、表皮构件和母题判读，以下术语描述几何，不自动代表施工构造或工程可行性。每个适用几何项记录“可见／推定／修正”和依据：可见指图上明确显示的关系；推定指进深、遮挡等需补充解释的关系；修正须写明原图问题和修改方式，包括已确认母题重复区域中的生成噪声处理。不能把有规律的变化统一掉。

“待确认”是独立状态，不替代上述三种标注：无法区分设计意图、构造错误或生成噪声时，先照图记录，填写“是；具体疑问”，不要擅自改形；问题解决后填写“否；确认依据”。不适用的几何项及其标注写“不适用”，依据说明原因。透视中的斜线不一定是实体斜壁，应结合正立面、局部图与底模交叉确认。

## 洞口与连接部位

| English | 中文 | 一句说明 | 在图上怎么辨认 |
| --- | --- | --- | --- |
| splayed window reveals | 外扩式窗洞侧壁／斜切窗洞内壁 | 洞口前缘与后部窗框之间由倾斜内壁连接，形成前后开口尺寸或位置差异。 | 同时寻找前口和后窗两道边界，看连接面是否向内收缩或偏移，不能只看阴影。 |
| angled jambs | 倾斜窗侧壁／斜窗侧帮 | 窗洞左右两侧的竖向壁面在平面上斜向连接前口与后窗。 | 近景或俯视中，侧壁前后边不在同一垂直于立面的线上；左右应分别判读。 |
| tapered side panels | 渐缩侧板 | 侧板的几何宽度或截面沿指定方向逐渐变化。 | 看侧板两条边是否非平行并逐渐收拢，记录渐缩方向；先排除透视缩短。 |
| front opening edge | 洞口前缘 | 外立面上界定洞口外口的边界。 | 沿外墙与洞口内壁交接的折线追踪，不把后部玻璃边当成前缘。 |
| recessed glazing | 后退玻璃面 | 玻璃位于洞口前缘后方，与前口之间形成进深。 | 看玻璃与侧壁、洞顶、底面相接的后部轮廓；单张图通常只能确认退后关系。 |
| rear glazing width | 后部玻璃宽度 | 洞口内部玻璃边界之间的横向距离。 | 对照后窗两侧框边判读，避免直接使用前口宽度。 |
| lateral offset | 横向偏移 | 后部窗面相对前口中心向左或向右偏置。 | 比较前后边界中心及左右露出的侧壁宽度，先统一观看方向。 |
| recess depth | 凹入进深 | 从立面前口向内到后部玻璃或背墙的距离。 | 近景中看侧壁、洞顶和底面长度；无尺寸或多视角约束时数值须标推定。 |
| sloped soffit / angled head reveal | 倾斜洞顶／斜洞顶内壁 | 洞口上部连接前口与后窗的内壁具有倾斜或高差。 | 看前后上沿及两侧交线是否形成可辨认的斜面，勿仅凭明暗判断坡度。 |
| multi-storey outer frame | 跨层外框 | 外框在视觉上连续包围两层或多层的洞口组合。 | 沿外框两侧向上追踪连续关系，同时查看中间是否仍有楼板。 |
| continuous splayed side wall | 连续斜侧壁 | 同一斜侧壁跨越相邻洞口或层段连续延伸。 | 看斜壁轮廓是否穿过层间位置保持连续，区别连续壁与各层独立小侧板。 |
| recessed intermediate slab edge | 退后的中间楼板前缘 | 跨层组合中的中间楼板保留，但其前缘退到外框后方。 | 在跨层区域寻找后方水平板边与阴影，不能把外框跨层误写成室内通高。 |
| unequal-width recessed openings | 不等宽凹入洞口 | 并列凹窗各自具有不同的前口、后窗宽度或偏移。 | 逐一标出每个前后口边界比较，不能根据相似外观合并成标准模块。 |
| continuous front balustrade | 连续前栏板／栏杆 | 一道前缘防护构件横跨多个洞口并保持连续。 | 追踪顶部和底部边线，检查中间隔墙是否遮断或穿越栏板。 |
| recessed balcony / loggia | 凹入式阳台／内凹廊 | 阳台空间位于建筑外轮廓以内，并有可辨认的底面和侧壁。 | 寻找栏板后方可使用底面及其与玻璃的距离，区别装饰浅凹槽。 |
| window mullion / transom | 窗竖梃／横档 | 竖梃和横档分别在竖向与横向分隔窗面。 | 识别玻璃面上的连续框条，勿把玻璃反射或背景线当成框条。 |
| parapet | 女儿墙 | 屋面边缘高出屋面的围护矮墙。 | 结合屋面或俯视确认顶边与屋面高差，不能把最高窗框直接当作女儿墙顶。 |
| roof-edge closure / end closure | 屋面边缘收口／端部收口 | 封闭新增立面与屋面或端部侧墙之间缝隙的连接部位。 | 俯视和端部近景中检查是否漏出空缝、构件断头或未封闭的洞顶。 |
| facade return / corner turn | 立面回折／转角 | 立面在平面上改变方向并延伸到侧面或后部。 | 用底模俯视确认转折点，再在透视中辨认连接关系，勿按效果图猜测转角位置。 |

以上覆盖参考成功案例记录中的斜壁、偏移凹窗、跨层外框、保留并退后的楼板、连续栏板及顶部与端部收口。不规则部分逐单元记录；经用户确认的母题重复部分记录母题、网格映射、变化规律与逐处特殊部位。

## 表皮构件

| English | 中文 | 一句说明 | 在图上怎么辨认 |
| --- | --- | --- | --- |
| vertical fins / ribs | 竖向肋片／竖肋 | 沿竖向延伸并从立面基面凸出的片状或条状构件。 | 找连续竖边、侧面和投影，分清实体肋片与玻璃竖梃，并核对是否跨层。 |
| rotated fins | 旋转肋片 | 每根肋片绕指定轴作整体旋转，其自身截面沿高度未必改变。 | 对照顶部或俯视中的截面方向，记录旋转轴与正负方向，不把透视宽度变化当成旋转。 |
| twisted fins | 扭转肋片 | 单根肋片的截面方向随高度或长度连续变化。 | 沿同一根肋片追踪上下截面和边线，区别单根扭转与相邻肋片角度不同。 |
| louvers | 百叶 | 多片叶片以明确间距和角度排列，形成遮阳或遮蔽层。 | 近景辨认每片叶片的前后边、倾角与净空，说明间距是中心距还是净距。 |
| folded panels / folded plates | 折板 | 单片板沿折线改变面方向，形成连续折面。 | 追踪同一板块的折棱与连接边，交叉核对阴影，避免把不同板之间的接缝当折线。 |
| sawtooth facade | 锯齿形立面 | 立面在平面或剖面上由交替倾斜的面形成锯齿轮廓。 | 在俯视或斜视中找到周期性的凸点与凹点，分别记录两侧角度、节距与深度。 |
| perforated panels | 穿孔板 | 板面上分布孔洞，孔径、孔距或开孔率可以固定或变化。 | 放大检查孔洞边缘及透光关系，区别真实孔洞与印刷纹理；看不清孔厚时标推定。 |
| spandrel panels | 层间板／层间封板 | 位于上下层窗带之间并遮蔽楼板边缘的围护板块。 | 对照底模楼板标高与窗上下沿定位，区别层间封板、楼板本体和外挑水平板。 |
| horizontal projecting panels | 水平外挑板 | 从立面基面向外伸出的水平片状构件，可形成层间遮阳。 | 在透视或俯视中确认外缘与基面的距离，勿仅凭正立面的横线认定其出挑深度。 |
| cladding panels | 饰面板块 | 以独立板块组成建筑表皮，板缝定义单元边界。 | 沿接缝追踪板块范围，分清板缝、折棱和色差，并核对与楼层、开间的对应关系。 |
